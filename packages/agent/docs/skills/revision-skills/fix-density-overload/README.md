# fix-density-overload

## Revision Target

- Section count
- Component count
- Detail disclosure level

## Fix Strategy

- Promote the primary content and collapse or demote secondary content.
- Prefer list/detail rhythm over repeated standalone cards when source supports it.
- Keep CTA reachable.
