Agent-facing rules:

- Follow the existing width rail, chrome, spacing, divider, and typography observations from `docs/design/`.
- Use component and token contracts as the source of valid visual expression.
- Use Divider only when source structure or selected pattern evidence requires separation.
- Do not create generic decorative gradients, arbitrary illustrations, emoji icons, or visual roles not represented by component/pattern evidence.
- Keep hierarchy legible through section order, component choice, and source-backed text rather than invented visual ornament.
